# Project instructions
- Diese App ist die Quelle fuer iPhone-App und Dashboard-Einbettung. Aenderungen an gemeinsamen Funktionen hier vornehmen.
- Standalone-, Vollbild-Einbettungs- und Kompaktmodus erhalten.
- Niemals Secrets in Frontend-Dateien oder public/config.js speichern.
- Keine kostenpflichtigen Dienste buchen oder Render-Tarif free aendern ohne Nutzerauftrag.
- Vor Abschluss npm test, npm run build und dotnet build backend/App.Api ausfuehren.
- Live-Daten niemals im Service Worker cachen; echte API-Ausfaelle sichtbar machen.
